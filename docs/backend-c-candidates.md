## 冻结标准（届时逐项打分）

1. 机制可区分性：时间编码实现与 TMRoPE 的差异能否支撑"机制方向跨家族复现"的主张；
2. 可检查性：位置/顺序的生成代码可读、可插桩；
3. 权重可得：开放权重 + 16 GiB（量化档）或 Colab 可跑；
4. 适配成本：≤ 后端 A 适配器工作量 × 1.5；
5. 与研究线的样本兼容：能吃研究线首轮的受控样本格式。
